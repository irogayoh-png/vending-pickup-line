One pickup line, 79 characters, as if a vending machine were flirting
with a passing human. The line was picked by an arena: 16 candidates
across seven angles, shortlisted to 6, fought pairwise in both orders
under the judge's brief, then the champion fought the gold set (the top
lines of the sibling "Pickup Lines for Machines" lane) and won on the
brief's own ordering -- the vending machine's world of glass, button
and falling snacks, not an AI's world of weights and context windows.

> Don't tap the glass — just press my button, I'll do the falling for both of us.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set), with no trailing newline.
